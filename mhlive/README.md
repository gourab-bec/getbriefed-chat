# MountainHouseLive.com — The Agent-Run Local Show Machine

**Mission:** make mountainhouselive.com the place Mountain House checks first — ahead of the
Facebook groups — with you as its most recognized face. Then clone the machine:
bayarealive.com (Oct), gourabbasulive.com (Phase 3).

## Honest targets (the machine optimizes these; vanity goals kill local shows)

| Milestone | Target | Why this number |
|---|---|---|
| Day 15 | Every MH household reached ≥1× (paid geo reach ~12k adults, freq 2) · 8 episodes live · 15 businesses in pipeline | A 6-mile geo is tiny — total awareness is genuinely buyable for ~$300 |
| Day 30 | 1,000 true fans (subs+follows), 3 episodes >5k views, businesses inbound ≥2/wk | 1k engaged fans in a 30k town = unavoidable; FB groups took 10 yrs for 20k |
| Day 60 | "Household name" proxy: 40% aided recognition (poll), MHLive cited/screenshotted inside the FB groups weekly | You don't beat the groups head-on — you become what they share |
| Aug 31 | Most-recognized-face proxy: stopped-in-public counter, event invites, county/CSD meeting mentions | Measurable stand-ins for an unmeasurable goal |

**The real flywheel (not ads):** every guest is a distributor. A featured business shares its
own episode to its own customers; 2 episodes/week × each guest's 500–3,000 local followers
compounds faster than any ad budget in a town this size. Ads are the match, guests are the fuel.

## Weekly autopilot loop (your time: ~4 hrs)
Mon: agent 02 sends this week's outreach + confirms 2 guests → Tue: agent 03 delivers prep
packets + releases → **Wed evening: YOU record both episodes back-to-back (2 hrs)** → Thu:
agent 04 edit spec + publish ep 1 → agent 05 launches its $20/day push → Fri: shorts wave +
guest share-kit delivered to the business → Sun: master agent's KPI report + next-week plan
→ **your 30-min review: approve guests, thumbnails, spend.**

## Rules the machine never breaks
No purchased followers/likes/views (platform ToS + FTC — and instantly visible in a small
town) · every guest signs the release before publishing · sponsored/paid segments disclosed
(#ad, FTC) · SMS/WhatsApp outreach only per the compliance box in agent 02 (TCPA) · HOA/CSD
and school content stays factual — the "source of truth" position dies with one bad take ·
minors on camera only with parental release.
